# 🛒 Blinkit Sales Dashboard | Power BI

### Interactive Sales & Outlet Performance Analysis

This project is an interactive **Power BI dashboard** built to analyse Blinkit's sales performance across different outlet types, outlet tiers, item categories, locations, and customer ratings.

The dashboard provides an overview of key business KPIs and allows users to explore sales performance through interactive visualisations and filters.

---

## 📌 Project Overview

The objective of this project is to transform raw Blinkit sales data into an interactive business intelligence dashboard that can be used to understand:

- Overall sales performance
- Outlet performance
- Item category performance
- Outlet size and location trends
- Customer ratings
- Sales distribution across different outlet tiers
- Historical sales trends

The project demonstrates the use of **Power Query, data cleaning, data transformation, DAX, data visualisation, and interactive dashboard design** in Power BI.

---

# 🎯 Project Objectives

The main objectives of the dashboard are:

- Analyse overall sales performance
- Create meaningful business KPIs
- Analyse sales across different outlet types
- Compare performance of different outlet tiers
- Analyse sales by item categories
- Understand the relationship between outlet characteristics and sales
- Analyse customer ratings
- Identify sales trends over time
- Create an interactive and user-friendly dashboard

---

# 📊 Dataset

The project uses a Blinkit sales dataset containing **1.2M+ sales records**.

The dataset contains information related to:

- Item sales
- Item categories
- Outlet types
- Outlet sizes
- Outlet locations
- Outlet establishment years
- Customer ratings
- Item visibility
- Item types

The data was cleaned and transformed before being used for dashboard development.

---

# 🧹 Data Preparation

The raw dataset was prepared using **Power Query** before creating the dashboard.

The data preparation process included:

- Loading the dataset into Power BI
- Inspecting data types
- Cleaning and transforming columns
- Handling missing or inconsistent values
- Formatting numerical and categorical fields
- Preparing the dataset for analysis

Power Query was used as the primary data transformation tool.

---

# 📐 DAX Measures

DAX was used to create important KPIs and analytical measures for the dashboard.

Key metrics include:

### Total Sales

Measures the overall sales generated across the dataset.

### Average Sales

Calculates the average sales value.

### Average Rating

Calculates the average customer rating.

These measures were then used across different dashboard visualisations to provide dynamic insights.

---

# 📌 Key Performance Indicators

The dashboard focuses on the following major KPIs:

| KPI | Purpose |
|---|---|
| **Total Sales** | Measures overall revenue/sales performance |
| **Average Sales** | Measures average sales value |
| **Average Rating** | Measures average customer rating |

These KPIs provide a quick overview of overall business performance.

# 📊 Dashboard Analysis

The dashboard provides analysis across multiple dimensions.

## 🏪 Outlet Analysis

Sales performance is analysed across different outlet characteristics, including:

- Outlet Type
- Outlet Size
- Outlet Location
- Outlet Tier
- Outlet Establishment Year

This helps identify which types of outlets contribute most to overall sales.

---

## 🥫 Item Category Analysis

The dashboard analyses sales across different item categories to understand:

- High-performing categories
- Low-performing categories
- Category contribution to overall sales

This can help identify which product categories are driving sales.

---

## 📍 Outlet Tier Analysis

The dashboard compares sales performance across different outlet tiers.

The analysis helps identify differences in sales performance between:

- Tier 1
- Tier 2
- Tier 3

In the analysis, **Tier 3 outlets show strong sales performance and contribute significantly to overall sales.**

---

## ⭐ Customer Rating Analysis

Customer ratings are analysed alongside sales information to understand customer perception and outlet/product performance.

---

## 📈 Sales Trend Analysis

Sales performance is also analysed across time using outlet establishment year and related dimensions.

This helps identify changes in sales performance across different outlet generations.
